# Super Store Sales Dashboard – Excel

## 📊 Project Overview

This project is an Excel-based Super Store Sales Dashboard created to analyze sales data and present key business information in an interactive dashboard.

## 🛠️ Tools & Skills Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Filtering
- Data Analysis
- Dashboard Design

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales
- Ship Mode Sales
- Zone-wise Sales
- Month-wise Quantity Sold
- Top 5 Cities
- Category-wise Transactions
- Consumer-wise Quantity
- Region and Year filtering

## 🎯 Project Objective

The objective of this project is to transform sales data into an interactive Excel dashboard that makes important information easier to analyze and understand.
